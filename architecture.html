End-to-End Architecture

Two tracks, six assignments. Track A (assignment 1) demonstrates Claude Code workflow practices against the Workforce Insights HR data. Track B (assignments 2–6) is one continuous pipeline: raw product data becomes governed tables, a vector index, a retrieval-augmented agent, and a chat UI, over the same live Unity Catalog objects throughout.

Real finding The deployed agent has no system prompt: an off-domain question got answered ("Paris") instead of declined, and with its vector-search tool unavailable it answered a product question from general LLM knowledge instead of erroring. The standalone RAG demo (assignment 4), which does have a grounding prompt, declines correctly. Documented, not silently patched.
Real finding Agent evaluation's RetrievalGroundedness/RetrievalRelevance scorers only apply cleanly to the 3 of 10 test questions that hit the vector index — the 7 that used UC functions show Error, not pass/fail, since there's no retrieval span to score.
Scope note The agent has no Genie tool — it can't answer aggregate questions ("how many products in Electronics?") that product_index alone can't serve.
